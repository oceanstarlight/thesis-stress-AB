# 2025 사건 사후 검증 (사전 등록 · 블라인드)

목적: 2025년에 파산·회생을 신청한 상장사에 대해, **2024-12-31까지 공개된 공시만으로** 도구가 경고를 냈는지 확인하고, 같은 규칙으로 뽑은 대조군(사건 없음)과 비교한다.

- 사전 등록 절차·수정 이력: `docs/validation/2025/PROTOCOL.md` (도구 실행 전에 작성)
- 원자료·스크립트: `docs/validation/2025/` (`python docs/validation/2025/analyze2.py`로 표 재현)

## 확증 편향을 막은 방법

| 위험 | 대응 |
|---|---|
| 맞힌 사례만 고르기 | 사건군을 사람이 고르지 않음. EDGAR 전문 검색(2025년 8-K 1.03 전부), DART 주요사항보고서(2025년 "회생절차개시신청·파산신청" 전부)로 기계적으로 수집 |
| 미래 정보 유입 | 사전 판정은 `lifecycle.run(t0=end=2024-12-31)`: 그날까지 공개된 공시만 (`pit.py`) |
| 이미 터진 사건 | 2024년 이전에 이미 1.03·회생 공시를 낸 회사 제외 (미국 13곳, 한국 2곳) |
| 오경보 무시 | 사건 기업마다 같은 업종의 무사건 회사를 규칙으로 1곳씩 대조군으로 뽑아 같이 돌림 |
| 결과 보고 조정 | 가중치·기준값은 고정. LLM 끔(결정적 실행) |

### 검증에서 찾은 버그 (규칙과 코드가 어긋난 곳)

1. **기준일에 이미 기준을 넘은 가정이 "유지"로 표시**: 남은 여유가 정확히 0일 때 `(margin or 1) <= 0`이 1로 바뀌어 통과. 카드에는 "이미 기준 초과"라고 쓰고 판정은 "유지"였다.
2. **EBITDA ≤ 0 강제 규칙이 가정이 있을 때만 작동**: 이자비용 태그가 없으면 가정이 하나도 기록되지 않아, 적자 기업이 "유지 0점"으로 나왔다. 문서의 규칙("점검일 EBITDA ≤ 0 → 재검토 필요")대로 지표를 직접 보게 고치고, 가정도 경고성 수시공시도 없으면 "판단 불가"로 바꿨다.

두 수정은 사건군과 대조군에 똑같이 적용되고, 가중치·기준값은 바꾸지 않았다. 회귀 테스트: `tests/test_lifecycle.py`의 `test_pre_investment_breach_with_zero_headroom_is_weakened`, `test_no_assumption_rows`.

### 어디서 구분력이 나오나

| 사유 | 미국 사건군 | 미국 대조군 |
|---|---|---|
| EBITDA ≤ 0 (강제) | 36/40 | 19/35 |
| 점수(가정 초과·수시공시) | 3/40 | 7/35 |
| 공시 강제(4.02·2.04) | 1/40 | 2/35 |
| 유지 | 0/40 | 7/35 |

- 구분력의 대부분은 **"적자 기업인가"**(EBITDA ≤ 0)에서 나온다. 사건군 90%, 대조군 54%. 소형주 위주인 대조군도 적자가 많아 오경보가 높다.
- EBITDA가 플러스인 회사만 보면 사건군 4/4가 경고(상장폐지 통지, 재작성, 소송·신용등급 8-K)를 받았다. 대조군은 16곳 중 9곳(56%)이 경고를 받았다.
- 대조군 오경보 중 3곳(GXO, EnerSys, PureCycle)은 **8-K 키워드 규칙** 때문이다. 실적 보도자료의 면책 문구(소송, 신용 약정)에 걸린 것으로 보인다. 개선 1순위다.

## 해석과 한계 (그대로 보고)

- **민감도는 높고 특이도는 낮다.** "깨질 수 있는 가정을 놓치지 않는다"는 목적에는 맞다. 하지만 지금 상태로는 "경고 = 위험"이라고 주장할 수 없다. 대조군의 77~80%도 재검토 필요가 나왔다.
- 표본이 소형주 위주다. 국부펀드가 실제로 보유할 대형주에서의 오경보율은 따로 재야 한다(예: S&P 500 무작위 표본).
- 파산은 가장 극단적인 결과다. 이 도구의 본래 목적인 "가정이 깨지는 조건"(이자보상·레버리지 기준 이탈) 예측은 별도 검증이 필요하다.
- 한국은 표본이 작고(6곳 판정 가능), 대조군 7곳 중 5곳이 판단 불가다. DART 본문 재무제표에 이자비용·감가상각비가 빠진 경우가 많다.
- 버그를 고친 뒤 같은 표본으로 다시 쟀으므로 v1 수치는 엄밀히 "사후 수정" 결과다. 다음 검증은 v1 코드를 고정하고 새 표본(예: 2026년 사건)으로 해야 한다.

## 개선 과제 (이번 검증에는 반영하지 않음)

1. 8-K 키워드 분류에서 면책 문구(forward-looking statements) 구간을 빼고 스캔한다. 대조군 오경보 원인이다.
2. 이자비용 대체 태그를 추가한다: `InterestIncomeExpenseNonoperatingNet`(부호 확인), `InterestPaidNet`(현금 기준 표시). ModivCare·Zynex 같은 판단 불가가 줄어든다.
3. 적자 기업은 "EBITDA ≤ 0" 하나로 묶지 말고 현금 소진 기간(현금 ÷ 분기 영업현금 유출)을 따로 본다. 바이오처럼 현금이 많은 적자 기업과 위기 기업을 구분하려는 것이다.
4. 대형주 대조군(S&P 500 무작위 50곳)으로 오경보율을 다시 잰다.
